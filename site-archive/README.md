# Site archive

Exported DigiMusic TV website pages (Freeway → HTML/PHP) with a **curated** `Resources/` set so the Digi player and nav chrome still resolve locally.

This showcase focuses on the **QuickTime Digi player era**. Live-console / third-party Flash player pages have been removed; nav “Live Broadcast” links point to `broadcast4.html`.

Not included (kept out to limit size):

- Softpress Freeway project binaries (`.freeway` / `.fwbackup`)
- Full original `Resources/` library (~759 files)

## Key pages

| File | Role |
|------|------|
| `default.html` | Home |
| `broadcast4.html` | QuickTime Digi player channel |
| `mission.html` / `connect.html` / `advertise.html` | Network story + monetization |
| `productplacement.html` | Placement / sponsorship surface |
